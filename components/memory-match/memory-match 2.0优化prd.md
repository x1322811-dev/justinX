2、游戏时长：调整为所有关卡配对环节的累计时长

* 游戏开始前页面调整：
1、游戏规则的提示文字，调整到卡片区域的上方
2、规则文字调整为：记住卡片的位置，在倒计时结束前完成配对！
3、规则文字居中展示，仅占据一行，避免换行

* 关卡展示优化
1、每开始新的一关时（包含第一关），先进行当前关卡数的展示
2、展示关卡过程中，所有卡片保持背面朝上
3、在原来游戏规则的位置，替换成关卡数，采用蓝色、大字体展示
4、关卡展示时间持续1秒，结束后进入记忆阶段

* 记忆阶段优化
1、关卡数消失后，在它本来的位置展示记忆时间倒计时模块
2、记忆时间倒计时模块分成两部分：
    1、文字：大字体、蓝色字体，“记住卡片的位置”
    2、进度条：在文字下方展示进度条，长度撑满整个屏幕，进度条随记忆时间倒计时从左向右缩短，缩短速度保持匀速
3、关卡数切换到记忆时间模块的过程自然流畅、保持页面高度不变，且卡片区域不会发生上下位移
4、文字切换增加淡入淡出的效果，保证切换自然流畅

* 配对阶段优化
1、现在配对阶段卡片区域上方还有一片空白区域，可以在这个区域内展示配对时间倒计时
2、倒计时模块格式为“00:00”，秒和十秒的数位采用上下滚动的数字切换动画
3、保持当前页面高度不发生任何抖动和错位，配对时间倒计时模块出现消失效果与整体页面切换效果一致、自然、流畅

* 通过成功过渡优化
1、目前在成功通过当前关卡到进入下一关之前，会有短暂的等待时间，这个时间内卡片区域上方会有一个空白区域，这个区域可以用来展示通关提示
2、通关提示文字格式为“恭喜你，通过第N关！”，采用蓝色、大字体展示，居中展示，仅占据一行
3、通关提示文字出现消失效果与整体页面切换效果一致、自然、流畅

* 游戏开始前：在卡片区域上方，居中展示游戏规则“记住卡片的位置，在限定时间内配对所有卡片”，保持仅占据一行。
* 游戏进行中：
    * 关卡展示阶段：所有卡片背面朝上，卡片区域上方大字展示“第N关”，不再展示游戏规则文字，本阶段持续1秒，进入记忆阶段
    * 记忆阶段：关卡信息消失，展示记忆时间倒计时，文字提示“记住卡片的位置”，用进度条逐渐消失的动画形式展示剩余记忆时间，同时所有卡片按随机顺序翻转至正面，翻转动画流畅，记忆阶段持续时间按之前prd中不同关卡的时长设定，结束后进入配对阶段。
    * 配对阶段：记忆时间结束 或 点击直接开始（跳过剩余记忆时间），进入配对阶段，记忆时间倒计时和文字提示消失，大字体居中展示配对时间倒计时，格式为“00.00”，精确到0.01秒，且数字采用上下滚动的形式表达时间的变化，动画类似于翻页时钟，配对阶段持续时间按之前prd中不同关卡的时长设定，结束后进入通关成功/失败阶段。
* 通关成功阶段：过关成功时，配对时间立即停止计时，并停留在剩余时间上，卡片区域清空所有卡片，居中展示 标题（恭喜通关）和数据（当前关卡数、所用时间），1.5s后切换到下一关的关卡展示阶段。
* 通过失败阶段：保持当前逻辑不变，点击重新挑战后，回到游戏开始前的状态。
